# Repository hosting, licensing, and CI baseline

## Context and Problem Statement

P0-01 leaves the GitHub org, license, and dependency-update tool to the project owner, and several CI
details to the implementer. This ADR records those choices so later prompts can substitute `<gh-org>` and
rely on the same CI shape in every repo.

## Decision Outcome

Owner decisions (**U**):

| #   | Decision                                                                                                                           |
| --- | ---------------------------------------------------------------------------------------------------------------------------------- |
| B1  | `<gh-org>` is **`gracefulinfra`**. Images are `ghcr.io/gracefulinfra/<repo>`.                                                      |
| B2  | All six repos are **public** (portfolio visibility; branch rulesets and required checks work on the free plan).                    |
| B3  | License: **Apache-2.0** in every repo (explicit patent grant; matches most of the stack).                                          |
| B4  | Dependency updates: **Renovate** (`config:best-practices`), with minor, patch, digest, and pin updates grouped into one weekly PR. |

Implementer defaults (**D**), changeable with a new ADR:

| #   | Decision                                                                                                                                                                                                                                                                                                                                           | Reason                                                                                |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| B5  | `main` is protected by a repository **ruleset**: PRs required (0 approvals, since this is a solo project), required status checks (strict), linear history, no force-push, no deletion, no bypass actors.                                                                                                                                          | Rulesets are the current GitHub mechanism; with no bypass, even admins go through CI. |
| B6  | Every Action is pinned by full commit SHA with a version comment; workflows default to `permissions: {}` and grant least privilege per job.                                                                                                                                                                                                        | Supply-chain hygiene; Renovate updates the SHAs.                                      |
| B7  | Image-producing repos (`relay-api`, `relay-media-workers`, `relay-site`, `relay-admin`) build `linux/amd64` + `linux/arm64` on every PR, and push only on `main`, tagged with the full git SHA. Images are signed with cosign keyless (GitHub OIDC) and carry a signed SPDX SBOM attestation generated by syft, plus BuildKit max-mode provenance. | Matches P0-01; SHA tags are immutable, and there is no `latest`.                      |
| B8  | Until product code exists, each image-producing repo ships a **smoke binary** that prints build metadata and exits.                                                                                                                                                                                                                                | P0-01 allows a minimal smoke image.                                                   |
| B9  | Base images are pinned by digest: `golang:1.27.1-trixie`, `gcr.io/distroless/static-debian13:nonroot`, `node:24.21.0-trixie-slim`, `gcr.io/distroless/nodejs24-debian13:nonroot`.                                                                                                                                                                  | Non-root, minimal runtime images.                                                     |
| B10 | TypeScript is pinned to **6.0.x**, not 7.x, because `typescript-eslint` 8.70.1 declares `typescript <6.1.0`.                                                                                                                                                                                                                                       | Revisit when typescript-eslint supports TS 7.                                         |
| B11 | pnpm denies dependency build scripts by default; allowances are listed with a reason in `pnpm-workspace.yaml`.                                                                                                                                                                                                                                     | pnpm 10+ default; keeps install-time code execution explicit.                         |
| B12 | The canonical version matrix lives in [`docs/version-matrix.md`](../docs/version-matrix.md) in this repo.                                                                                                                                                                                                                                          | One place to verify and update pins.                                                  |

### Consequences

- Good, because every repo shares the same CI shape and required-check names, so later prompts can assume them.
- Bad, because public repos expose work in progress; secrets must never reach git (already a convention).
- Bad, because with no ruleset bypass, even trivial fixes need a PR and green CI.

### Confirmation

P0-01 acceptance evidence: green CI on `main` in all six repos, a blocked test PR in `relay-api`, and a
successful `cosign verify` of a GHCR image.
